# وكيل الشهباء العقاري - بوت تيليجرام + Gemini

## شو هاد؟
بوت تيليجرام ذكي، بيفهم ويرد عليك بالعامية السورية، مبني على Google Gemini (مجاني بالكامل).
موصول بموقع المكتب (alshabaoffice.netlify.app) كمصدر أساسي، وعنده بحث حقيقي بالإنترنت، وفهم صور ورسايل صوتية.

## خطوات التشغيل (من الموبايل، بدون لابتوب)

### 1. ارفع هالملفات على GitHub
- افتح github.com وسجل دخول
- سوي مستودع (Repository) جديد، اسمه مثلاً `wakilshaba-agent`
- ارفع الملفات الأربعة: `main.py`, `requirements.txt`, `Procfile`, `README.md`

### 2. جهز التوكن تبع البوت (لو ما عندك واحد جاهز)
- روح لبوت **@BotFather** بتيليجرام
- ابعتلو `/newbot` واتبع التعليمات
- رح يعطيك توكن (سلسلة طويلة) - هاد الـ `TELEGRAM_TOKEN`

### 3. جهز مفتاح Gemini (لو ما عندك واحد جديد لسا)
- aistudio.google.com → Get API key
- هاد الـ `GEMINI_API_KEY`

### 4. انشر على Railway
- افتح railway.app وسجل دخول (بنفس حساب Wakilshaba يلي عندك)
- **New Project → Deploy from GitHub repo** → اختار المستودع يلي رفعتو
- بعد ما يخلص الإعداد الأولي، روح لتبويب **Variables** وضيف:
  - `TELEGRAM_TOKEN` = التوكن يلي أخدتو من BotFather
  - `GEMINI_API_KEY` = مفتاح Gemini يلي أخدتو
- Railway رح يشغل البوت لحاله من الـ Procfile

### 5. جرب البوت
- افتح تيليجرام ودور عبوتك وابعتلو `/start`
- جرب `/site` لتحليل شامل فوري لموقع المكتب
- احكيلو أي شي، ابعتلو صورة عقار، أو رسالة صوتية

## أوامر البوت
- `/start` - بداية المحادثة
- `/site` - تحليل شامل فوري لموقع المكتب (عدد عقارات، أسعار، اقتراحات)
- `/reset` - يمسح ذاكرة المحادثة الحالية ويبلش من جديد

## المميزات الحالية (المرحلة 1)
- ذكاء Gemini 2.5 Pro مع تحول تلقائي لـ Flash لو خلصت الحصة اليومية
- فهم صور ورسايل صوتية
- بحث حقيقي بالإنترنت + قراءة أي رابط
- موقع المكتب كمصدر أساسي للمعلومات
